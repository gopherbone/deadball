# DEADBALL audio — integration guide

Owner: audio agent. Entry file: `import "audio/audio"` (defines the global `Audio`).
The full API is documented at the top of `audio/audio.lua`. Everything is lazy and every
call is safe before `Audio.init()`; unknown names are ignored (printed once), never errors.

Contents of `audio/`:

| path | what |
|---|---|
| `audio.lua` | the API (`Audio.*`) |
| `organ.lua`, `sfx.lua` | internal: organ instruments + "stadium PA" chain, synthesized SFX fallbacks |
| `manifest.lua` | GENERATED by `tools/audio/build.py`: cue → recording file and/or MIDI arrangement |
| `music/*.wav` | trimmed lo-fi vintage/permissive recordings (IMA ADPCM, streamed) |
| `sfx/*.wav` | sampled sound effects (IMA ADPCM, loaded on first use) |
| `midi/*.mid` | our own organ arrangements (written by `tools/audio/compose.py`) |
| `organ/*.wav` | organ note samples (16-bit PCM, looped by the synth voices) |
| `credits.json` | `[{file, title, author, url, license, year}]` for the in-game Credits page |

Rebuild everything: `python3 tools/audio/build.py` (needs ffmpeg; raw downloads live in
`tools/audio/.cache/`, which is git-ignored).

## Call sites

### Shell (main.lua / app / sites / ui)

| when | call |
|---|---|
| once at startup (after settings load) | `Audio.init()` then `Game.applyVolumes()` (already pushes `setMusicVolume` / `setSfxVolume` / `setMuted`) |
| boot screen dial-up | `local dur = Audio.sfx("modem")` — a real 56k handshake, ≈12.6 s (dial, DTMF, answer tone, screech); let any button skip it with `Audio.stopSfx("modem")`. Want it short? `Audio.sfx("modem_synth")` (≈4.5 s). ui/sound.lua's `Sfx.modem()` already routes to `"modem"` |
| desktop / idle browsing | `Audio.play("summertime", { loop = true, fade = 1.5 })` — vary with `"sweet_georgia"` or `"stretch_vamp"`; stop with `Audio.stop(nil, 1)` when entering BallCast |
| UI focus / select / back / error | `Sfx.*` in ui/sound.lua already maps to `Audio.sfx("blip"/"select"/"back"/"error")` |
| new mail arrives (`Sfx.mail()` in app/state.lua) | `Audio.stinger("new_mail")` (or keep `Audio.sfx("mail")` for a quieter chime) |
| wire ticker scrolling new lines | `Audio.sfx("telegraph", 0.6)` per new line (1.75 s real sounder); while the Wire site is open, `Audio.ambience("teletype", 0.25)`, and `Audio.ambience(nil)` on leaving |
| bet placed | `Audio.sfx("cash_register")` (a 1912 National Cash Register) |
| bet result revealed | win: `Audio.stinger("bet_won")`, then for a big win `Audio.play("stars_stripes")`; loss: `Audio.stinger("bet_lost")`; busted/blowout: `Audio.play("funeral_march")` |
| card pack opening | `Audio.sfx("pack_tear")` on the tear, `Audio.stinger("pack_opened")` on the reveal, `Audio.sfx("card_flip")` per card, `Audio.sfx("card_shuffle")` in the binder |
| arrests / busted crew (events, mail) | `Audio.stinger("arrest")`; harsher: `Audio.sfx("police_whistle")` or `Audio.sfx("siren")`, then `Audio.sfx("handcuffs")` / `Audio.sfx("jail_door")` |
| phone/event card arrives | `Audio.sfx("phone_ring")` |
| news site / typing a comment | `Audio.sfx("typewriter")`, `Audio.sfx("typewriter_bell")` on submit |
| idle alternatives | `Audio.play("ragtime", { loop = true })` (1912 Black Diamond Rag); `Audio.sfx("pa_chime")` before a PA-style announcement |
| life events (wedding, birth, retirement) | `Audio.play("wedding_march")` or `"bridal_chorus"` (weddings) |
| commissioner / officials / league office pages | `Audio.play("hail_chief")` |
| raccoon incident / clown story in the news | `Audio.play("gladiators")` |
| Settings page | sliders call `Game.applyVolumes()`; add a "Music" slider (`musicVol`) next to SFX; optional "Stadium PA" toggle → `Audio.setPA(flag)` |
| Credits page | read `audio/credits.json` (`json.decodeFile`) and list `title — author — license — url` |

### BallCast (ballcast agent)

| when | call |
|---|---|
| entering a replay | `Audio.stop(nil, 0.8)`; optionally `Audio.ambience("crowd_ambience", 0.35)`; consider `Audio.setLowCPU(true)` while the 3D renderer runs, `false` on exit |
| leaving / pausing a replay | `Audio.ambience(nil)`; `Audio.stop()` |
| 7th-inning stretch (middle of the 7th: `b.kind == "half"` going to the bottom of the 7th) | `Audio.play("take_me_out", { loop = false })` — whichever candidate `tools/audio/selection.json` → `aliases.take_me_out` names (`take_me_out_meeker` 1908 cylinder ≈27 s, `take_me_out_haydn` 1908 Victor disc ≈53 s, `take_me_out_organ` our organ arrangement ≈41 s, `take_me_out_ballpark` live ballpark organ + crowd ≈44 s); scrubbing/fast-forward → `Audio.stop("take_me_out", 0.5)` |
| other half-inning breaks | `Audio.stinger("charge")` (organ "Charge!"; `"charge_band"` = full brass band) or `Audio.play("stretch_vamp", { loop = false })` |
| bat contact | `Audio.sfx("bat_crack")` |
| ball into the mitt | `Audio.sfx("mitt_pop")` |
| called strike three | `Audio.sfx("strike_call")` (synth "steee-rike"; no clean licensed umpire voice exists), then `Audio.stinger("strikeout")` |
| groans / near misses / crowd rhythm | `Audio.sfx("crowd_ooh")`, `Audio.sfx("crowd_groan")`, `Audio.sfx("crowd_clap")` (rhythmic clapping for rallies) |
| home run | `Audio.sfx("bat_crack")`, `Audio.sfx("crowd_roar")` as it clears the wall (a real MLB home-run roar), then `Audio.stinger("home_run")` |
| star batter strikes out | `Audio.play("casey", { loop = false })` — the 1909 "Casey at the Bat" ending ("...mighty Casey has struck out") |
| error in the field | `Audio.stinger("error")` + `Audio.sfx("crowd_boo", 0.6)` |
| ejection incident | `Audio.sfx("whistle")`, then `Audio.stinger("ejection")` ("you're outta here") |
| raccoon incident on the field | `Audio.play("gladiators", { loop = false })` (stop it when the incident overlay ends) |
| rally / big inning for the home team | `Audio.play("hat_dance", { loop = false })` or `Audio.stinger("charge")` |
| walk-up of a featured batter | `Audio.play("pop_weasel", { loop = false })` |
| vendor flavour between pitches (rare) | `Audio.sfx("vendor_call", 0.5)` / `Audio.sfx("vendor_bell", 0.5)` |
| final out — home win / blowout loss | `Audio.play("stars_stripes")` / `Audio.play("funeral_march")` |

Note for the ballcast agent: `BallCast.Audio.sfx("organ")` in `ballcast/audio.lua` schedules
several future notes on one synth; a synth only buffers one pending note, so only the last
note sounds. Replace it with `Audio.stinger("charge")` when `Audio` is present.

## CPU / memory notes

- Recordings stream through ONE `fileplayer` (IMA ADPCM, 22 kHz mono): ~11 KB/s, and
  measured ≈ 1.6–1.9 % audio CPU on a Playdate (rev A).
- Organ (MIDI) cues: ≤ 8 sample-synth voices (a real transistor combo organ, CC0, sampled at
  C3/C4/C5 and looped) + a 4-effect PA chain (2 filters, overdrive, 0.3 s delay) that is only
  attached while organ music plays. Measured ≈ 19–22 % audio CPU with the PA chain on.
  `Audio.setLowCPU(true)` mutes chords/bass/chorus tracks and drops the PA chain — use it during
  BallCast replays, or prefer recordings there (most cues are recordings anyway).
- Stingers duck the music to 30 % and restore it when they finish.
- SFX samples load on first use and stay cached (a few KB each).
- Fades run on `playdate.timer` — `playdate.timer.updateTimers()` must be called every frame
  (main.lua does).
